What is Vue? {#what-is-vue}

Vue (pronounced /vjuː/, like view) is a JavaScript framework for building user interfaces. It builds on top of standard HTML, CSS, and JavaScript and provides a declarative, component-based programming model that helps you efficiently develop user interfaces of any complexity.

Here is a minimal example:

import { createApp } from 'vue'

createApp({
  data() {
    return {
      count: 0
    }
  }
}).mount('#app')

import { createApp, ref } from 'vue'

createApp({
  setup() {
    return {
      count: ref(0)
    }
  }
}).mount('#app')

<div id="app">
  <button @click="count++">
    Count is: {{ count }}
  </button>
</div>

Result

The above example demonstrates the two core features of Vue:

  • Declarative Rendering: Vue extends standard HTML with a template syntax that allows us to declaratively describe HTML output based on JavaScript state.

  • Reactivity: Vue automatically tracks JavaScript state changes and efficiently updates the DOM when changes happen.

You may already have questions - don't worry. We will cover every little detail in the rest of the documentation. For now, please read along so you can have a high-level understanding of what Vue offers.

:::tip Prerequisites The rest of the documentation assumes basic familiarity with HTML, CSS, and JavaScript. If you are totally new to frontend development, it might not be the best idea to jump right into a framework as your first step - grasp the basics and then come back! You can check your knowledge level with these overviews for JavaScript, HTML and CSS if needed. Prior experience with other frameworks helps, but is not required. :::

Giới thiệu Vue 3 cho người mới phát triển website

Giới thiệu

Khi xây dựng giao diện website, bạn cần mô tả nội dung hiển thị và cập nhật giao diện khi dữ liệu thay đổi. Vue hỗ trợ công việc này dựa trên HTML, CSS và JavaScript, với cách lập trình khai báo và tổ chức giao diện thành các thành phần.

Đây là tài liệu dành cho Vue 3. Nếu bạn đang sử dụng Vue 2, hãy lưu ý:

  • Vue 2 đã kết thúc hỗ trợ vào ngày 31 tháng 12 năm 2023. Xem thêm thông tin tại Vue 2 EOL.
  • Nếu muốn nâng cấp từ Vue 2, hãy tham khảo hướng dẫn chuyển đổi.

Vue là gì?

Vue, phát âm là /vjuː/ giống từ tiếng Anh view, là một framework JavaScript dùng để xây dựng giao diện người dùng. Dựa trên các công nghệ web tiêu chuẩn, Vue cung cấp mô hình lập trình khai báo, hướng thành phần, giúp bạn phát triển hiệu quả các giao diện với nhiều mức độ phức tạp.

Dưới đây là một ví dụ tối giản. Đoạn mã đầu tiên tạo ứng dụng với trạng thái count có giá trị ban đầu là 0:

import { createApp } from 'vue'

createApp({
  data() {
    return {
      count: 0
    }
  }
}).mount('#app')

Một cách viết khác cho cùng ví dụ sử dụng setup() và ref():

import { createApp, ref } from 'vue'

createApp({
  setup() {
    return {
      count: ref(0)
    }
  }
}).mount('#app')

Cả hai cách trên đều kết hợp với mẫu HTML sau:

<div id="app">
  <button @click="count++">
    Count is: {{ count }}
  </button>
</div>

Kết quả: nút hiển thị giá trị hiện tại của count. Khi nhấn nút, giá trị tăng lên và nội dung hiển thị được cập nhật tương ứng.

Hai đặc điểm cốt lõi của Vue

  • Kết xuất khai báo: Vue mở rộng HTML tiêu chuẩn bằng cú pháp mẫu, cho phép bạn mô tả đầu ra HTML dựa trên trạng thái JavaScript.
  • Tính phản ứng: Vue tự động theo dõi các thay đổi của trạng thái JavaScript và cập nhật DOM một cách hiệu quả khi có thay đổi.

Nếu ví dụ này khiến bạn có thêm câu hỏi, bạn chưa cần hiểu hết mọi chi tiết ngay. Các phần tiếp theo của tài liệu sẽ giải thích cụ thể; mục tiêu ở đây là giúp bạn có cái nhìn tổng quan về những gì Vue cung cấp.

Kiến thức cần có trước khi học

Phần còn lại của tài liệu giả định rằng bạn đã có kiến thức cơ bản về HTML, CSS và JavaScript. Nếu hoàn toàn mới với phát triển frontend, bạn nên nắm vững những nền tảng này trước khi bắt đầu học framework, rồi quay lại tìm hiểu Vue.

Bạn có thể kiểm tra và củng cố kiến thức qua các tài liệu tổng quan về JavaScript, HTML và CSS. Kinh nghiệm với framework khác có thể giúp ích, nhưng không phải là điều kiện bắt buộc.
