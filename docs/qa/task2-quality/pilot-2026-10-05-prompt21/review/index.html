What is Vue? {#what-is-vue}

Vue (pronounced /vjuː/, like view) is a JavaScript framework for building user interfaces. It builds on top of standard HTML, CSS, and JavaScript and provides a declarative, component-based programming model that helps you efficiently develop user interfaces of any complexity.

Here is a minimal example:

import { createApp } from 'vue'

createApp({
  data() {
    return {
      count: 0
    }
  }
}).mount('#app')

import { createApp, ref } from 'vue'

createApp({
  setup() {
    return {
      count: ref(0)
    }
  }
}).mount('#app')

<div id="app">
  <button @click="count++">
    Count is: {{ count }}
  </button>
</div>

Result

The above example demonstrates the two core features of Vue:

  • Declarative Rendering: Vue extends standard HTML with a template syntax that allows us to declaratively describe HTML output based on JavaScript state.

  • Reactivity: Vue automatically tracks JavaScript state changes and efficiently updates the DOM when changes happen.

You may already have questions - don't worry. We will cover every little detail in the rest of the documentation. For now, please read along so you can have a high-level understanding of what Vue offers.

:::tip Prerequisites The rest of the documentation assumes basic familiarity with HTML, CSS, and JavaScript. If you are totally new to frontend development, it might not be the best idea to jump right into a framework as your first step - grasp the basics and then come back! You can check your knowledge level with these overviews for JavaScript, HTML and CSS if needed. Prior experience with other frameworks helps, but is not required. :::

Giới thiệu Vue 3 cho người mới phát triển website

Giới thiệu Vue 3

Khi xây dựng giao diện website, bạn cần mô tả nội dung hiển thị và cập nhật giao diện khi dữ liệu thay đổi. Vue hỗ trợ công việc này dựa trên HTML, CSS và JavaScript tiêu chuẩn, với cách lập trình khai báo và tổ chức giao diện thành các thành phần.

Lưu ý: Nội dung này giới thiệu Vue 3. Vue 2 đã kết thúc hỗ trợ vào ngày 31 tháng 12 năm 2023. Bạn có thể tìm hiểu thêm tại trang Vue 2 EOL. Nếu đang nâng cấp từ Vue 2, hãy tham khảo hướng dẫn chuyển đổi.

Vue là gì?

Vue, phát âm là /vjuː/ giống từ view trong tiếng Anh, là một framework JavaScript dùng để xây dựng giao diện người dùng. Vue cung cấp mô hình lập trình khai báo, dựa trên thành phần, giúp bạn phát triển hiệu quả các giao diện với nhiều mức độ phức tạp khác nhau.

Ví dụ tối giản

Ví dụ dưới đây tạo một ứng dụng có trạng thái count, với giá trị ban đầu là 0. Phần JavaScript có thể được viết theo một trong hai cách sau:

import { createApp } from 'vue'

createApp({
  data() {
    return {
      count: 0
    }
  }
}).mount('#app')

import { createApp, ref } from 'vue'

createApp({
  setup() {
    return {
      count: ref(0)
    }
  }
}).mount('#app')

Phần HTML hiển thị giá trị đếm trong một nút:

<div id="app">
  <button @click="count++">
    Count is: {{ count }}
  </button>
</div>

Khi nhấn nút, count tăng lên và giá trị hiển thị được cập nhật. Ví dụ này minh họa hai đặc điểm cốt lõi của Vue:

  • Kết xuất khai báo: Vue mở rộng HTML tiêu chuẩn bằng cú pháp template, cho phép bạn mô tả đầu ra HTML dựa trên trạng thái JavaScript. Trong ví dụ, {{ count }} mô tả giá trị cần hiển thị.
  • Tính phản ứng: Vue tự động theo dõi thay đổi của trạng thái JavaScript và cập nhật DOM một cách hiệu quả khi thay đổi xảy ra.

Nếu bạn chưa hiểu hết các chi tiết trong ví dụ, đừng lo. Những phần tiếp theo của tài liệu sẽ giải thích cụ thể hơn. Ở bước này, mục tiêu là nắm được cách Vue kết nối trạng thái JavaScript với giao diện.

Kiến thức cần có trước khi bắt đầu

Các phần tiếp theo của tài liệu giả định rằng bạn đã có kiến thức cơ bản về HTML, CSS và JavaScript. Nếu hoàn toàn mới với phát triển frontend, bạn nên học nền tảng trước thay vì bắt đầu ngay bằng một framework, rồi quay lại tìm hiểu Vue.

Để kiểm tra hoặc củng cố kiến thức, bạn có thể tham khảo các tài liệu tổng quan về JavaScript, HTML và CSS. Kinh nghiệm với framework khác sẽ hữu ích, nhưng không phải điều kiện bắt buộc.

Vue 3 cho người mới: giao diện cập nhật theo trạng thái như thế nào?

Với Vue, bạn mô tả giao diện dựa trên trạng thái JavaScript; khi trạng thái thay đổi, Vue tự động cập nhật giao diện. Vue là framework JavaScript để xây dựng giao diện người dùng trên nền HTML, CSS và JavaScript tiêu chuẩn. Tên Vue được đọc là /vjuː/, giống từ view trong tiếng Anh.

Nội dung này giới thiệu Vue 3. Vue cung cấp mô hình lập trình khai báo và dựa trên component — các thành phần giao diện — giúp xây dựng giao diện từ đơn giản đến phức tạp.

Hai cơ chế cốt lõi của Vue

Kết xuất khai báo (Declarative Rendering): bạn dùng template để mô tả HTML cần hiển thị dựa trên trạng thái JavaScript. Vue mở rộng HTML tiêu chuẩn bằng cú pháp template, chẳng hạn cú pháp để hiển thị giá trị của một biến.

Tính phản ứng (Reactivity): Vue tự động theo dõi thay đổi trạng thái JavaScript và cập nhật DOM khi có thay đổi. Ví dụ bộ đếm dưới đây minh họa cách hai cơ chế này phối hợp.

Ví dụ bộ đếm

Nguồn đưa ra hai cách khai báo JavaScript cho cùng một bộ đếm. Chỉ dùng một trong hai đoạn, không chạy cả hai cùng lúc. Cách thứ nhất khai báo count với giá trị ban đầu là 0 trong data(), rồi gắn ứng dụng vào phần tử có ID app:

import { createApp } from 'vue'

createApp({
  data() {
    return {
      count: 0
    }
  }
}).mount('#app')

Cách thứ hai dùng setup() và ref(0) để khai báo trạng thái đếm, cũng bắt đầu từ 0:

import { createApp, ref } from 'vue'

createApp({
  setup() {
    return {
      count: ref(0)
    }
  }
}).mount('#app')

Cả hai cách đều dùng phần HTML sau:

<div id="app">
  <button @click="count++">
    Count is: {{ count }}
  </button>
</div>

Trong template, {{ count }} hiển thị giá trị của count, còn @click="count++" tăng giá trị đó thêm một mỗi lần bấm nút. Theo logic của đoạn code, nút ban đầu hiển thị Count is: 0; sau một lần bấm, nội dung trở thành Count is: 1. Bạn khai báo nơi hiển thị số đếm, còn Vue theo dõi thay đổi của count và cập nhật nội dung tương ứng trong DOM.

Cần biết gì trước khi học?

Tài liệu giả định bạn đã có kiến thức cơ bản về HTML, CSS và JavaScript. Nếu hoàn toàn mới với lập trình frontend, nên học các nền tảng này trước khi bắt đầu với framework. Bạn có thể kiểm tra kiến thức hoặc ôn lại qua các phần tổng quan của MDN về JavaScript, HTML và CSS. Kinh nghiệm với framework khác có ích, nhưng không bắt buộc.
